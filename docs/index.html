Features

为替代官方 App 而生

直连、预览、传输，全链路精简实现；协议层插件化，为扩展而设计。

RTSP 实时图传

基于 Media3 的低延迟实时预览，画面流畅，替代官方卡的图传体验。

文件传输

文件列表、应用内解码缩略图、断点续传下载，一键发布到系统相册。

Wi-Fi 直连

相机热点直连与局域网扫描（API 24+ / 29+ 双路径），不依赖外网。

协议插件化

实现 CameraProtocol 并注册即可接入新相机，核心与 UI 零改动。

运行时自动探测

逐个探测已注册协议并读取真实型号，不依赖写死的机型表。

精简轻量

没有高德、全景、友盟等重型 SDK——相比官方 153MB 的安装包，保持克制。

Quick Start

快速开始

环境要求：JDK 21、Android SDK（compileSdk 35）。在 local.properties 中配置 sdk.dir。

1构建 Android APK

./gradlew :composeApp:assembleDebug

产物：composeApp/build/outputs/apk/debug/composeApp-debug.apk

2启动模拟器

./gradlew :simulator:run
  • 模拟完整 hi3510 CGI：状态、电量、拍照/录像、文件列表、缩略图、下载
  • 用 SIM_PORT=8081 可换端口

3连接并体验

./gradlew :composeApp:run

App 内「手动连接」输入 host:port：模拟器 10.0.2.2:8080，真机用局域网 IP。

真机注意：Wi-Fi 扫描需要位置权限——Android 在 API 33+ 声明 NEARBY_WIFI_DEVICES 时仍会拒绝无定位权限的 startScan，App 会在首次扫描时主动申请。
